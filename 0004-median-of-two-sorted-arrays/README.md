## 🎯 Problem summary

<h2><a href="https://leetcode.com/problems/median-of-two-sorted-arrays/">4. Median of Two Sorted Arrays</a></h2><h3>Hard</h3><hr><p>Given two sorted arrays <code>nums1</code> and <code>nums2</code> of size <code>m</code> and <code>n</code> respectively, return <strong>the median</strong> of the two sorted arrays.</p>

<p>The overall run time complexity should be <code>O(log (m+n))</code>.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<pre>
<strong>Input:</strong> nums1 = [1,3], nums2 = [2]
<strong>Output:</strong> 2.00000
<strong>Explanation:</strong> merged array = [1,2,3] and median is 2.
</pre>

<p><strong class="example">Example 2:</strong></p>

<pre>
<strong>Input:</strong> nums1 = [1,2], nums2 = [3,4]
<strong>Output:</strong> 2.50000
<strong>Explanation:</strong> merged array = [1,2,3,4] and median is (2 + 3) / 2 = 2.5.
</pre>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>nums1.length == m</code></li>
	<li><code>nums2.length == n</code></li>
	<li><code>0 &lt;= m &lt;= 1000</code></li>
	<li><code>0 &lt;= n &lt;= 1000</code></li>
	<li><code>1 &lt;= m + n &lt;= 2000</code></li>
	<li><code>-10<sup>6</sup> &lt;= nums1[i], nums2[i] &lt;= 10<sup>6</sup></code></li>
</ul>

### My solution

```python3
class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        # Ensure nums1 is smaller
        if len(nums1) > len(nums2):
            nums1, nums2 = nums2, nums1
        
        m, n = len(nums1), len(nums2)
        total = m + n
        half = (total + 1) >> 1
        
        # Handle edge cases first
        if m == 0:
            return nums2[n // 2] if n & 1 else (nums2[n // 2 - 1] + nums2[n // 2]) * 0.5
        
        left, right = 0, m
        
        # Cache array access methods for speed
        nums1_get = nums1.__getitem__
        nums2_get = nums2.__getitem__
        
        while left <= right:
            i = (left + right) >> 1
            j = half - i
            
            # Optimized boundary checks
            maxLeft1 = nums1_get(i - 1) if i else float('-inf')
            minRight1 = nums1_get(i) if i < m else float('inf')
            
            maxLeft2 = nums2_get(j - 1) if j else float('-inf')
            minRight2 = nums2_get(j) if j < n else float('inf')
            
            if maxLeft1 <= minRight2 and maxLeft2 <= minRight1:
                if total & 1:
                    return float(max(maxLeft1, maxLeft2))
                else:
                    return (max(maxLeft1, maxLeft2) + min(minRight1, minRight2)) * 0.5
            elif maxLeft1 > minRight2:
                right = i - 1
            else:
                left = i + 1
        
        return 0.0

```
